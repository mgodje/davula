# About Project
This project presents an interactive, VR-compatible 3D model of the Davula, an Assyrian goblet drum. It was used in two user studies exploring cultural heritage learning through interaction with a virtual artifact.

Users can view the drum in a web browser after a brief loading period. With a compatible VR headset, they can explore an immersive experience that introduces the drum’s history and teaches them how to play it.

The project aims to increase awareness of Assyrian cultural heritage and celebrate the resilience and traditions of the Assyrian people.
